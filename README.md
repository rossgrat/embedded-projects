# Embedded projects

Register-level C learning projects for the Nucleo-L4R5ZI board and STM32L4R5ZI microcontroller.

| Project | Entry point |
| --- | --- |
| LED blink and pulse | [Plan](das-blinkenlights/PLAN.md) and [C exercises](das-blinkenlights/c) |
| UART firmware updates | [Bootloader plan](bootloader/PLAN.md) |
| Preemptive kernel and shell | [RTOS plan](os/PLAN.md) |
| Game Boy emulator | [Emulator plan](gb/PLAN.md) |

Start with the LED exercises and their Makefiles.
Use the project plans for prerequisites and checkpoints; a plan is not evidence of completed hardware validation.
More possible exercises are listed in [IDEAS.md](IDEAS.md).
